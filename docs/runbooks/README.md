# Runbooks

Write one per operational scenario as the system grows. Planned:

- Kite disconnect or token expiry
- LLM provider outage
- Budget exhausted (what degrades, what blocks)
- Bad or stale market data
- [NSE trading calendar](trading-calendar.md): yearly update and urgent holidays (written)
- Unexpected paper fill
- Using the kill switch
- Restoring Postgres from backup
